MUR · SISTEMA D'HONDT — GITHUB PAGES

Contenido listo para publicar como una página estática en GitHub Pages.

ARCHIVOS
- index.html: página principal.
- manifest.webmanifest: permite instalar/agregar a la pantalla de inicio en navegadores compatibles.
- sw.js: cachea la aplicación para que pueda seguir funcionando sin conexión después de la primera carga.
- icon-180.png / icon-512.png: iconos.
- .nojekyll: evita el procesamiento innecesario de Jekyll.

PUBLICAR EN GITHUB
1. Crear un repositorio nuevo en GitHub.
2. Subir TODO el contenido de esta carpeta, dejando index.html en la raíz del repositorio.
3. Ir a Settings → Pages.
4. En Build and deployment, elegir: Deploy from a branch.
5. Seleccionar la rama main y la carpeta /(root), y guardar.
6. Esperar a que GitHub publique el sitio. En Settings → Pages aparecerá la dirección pública.

La dirección normalmente tendrá esta forma:
https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/

USO EN CELULAR
- Abrir el enlace desde WhatsApp.
- En iPhone se abrirá en Safari.
- En Android se abrirá en el navegador predeterminado.
- Se puede agregar a la pantalla de inicio desde el navegador.

NOTA
La aplicación no necesita librerías externas para calcular y mostrar los resultados. Los datos se guardan localmente en el navegador del dispositivo.
